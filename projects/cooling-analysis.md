# Conformal cooling & geometry analysis

**Focus:** geometry analysis and computational tools for cooling-channel research.  
**Status:** research prototype. Source repository: private.

This project brings part geometry, local wall thickness and imported thermal results
into a desktop analysis workflow. It supports the inspection and development of
conformal cooling channels around STL/STEP parts.

## Workflow

1. Load the part and inspect its mesh geometry.
2. Compute and visualize local wall thickness.
3. Import and map external thermal results.
4. Inspect cooling-channel geometry and export CAD/data for further study.

## Engineering scope

The project combines geometry processing, field visualization and CAD export.
Thermal results are imported from external simulation software for inspection
and further cooling-channel research.

**Areas:** Python · STL/STEP · thickness analysis · thermal fields · conformal cooling.

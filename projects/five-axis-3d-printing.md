# 5-axis 3D printing research

A research project exploring motion and print orientation in multi-axis plastic
additive manufacturing.

The project provides a virtual setting for studying five-axis printing workflows
before using a physical machine. It lets the user observe printing motion and
explore how the orientation of the part affects the printing process.

The current demonstrator focuses on virtual motion and print orientation;
physical machine validation remains future work.
